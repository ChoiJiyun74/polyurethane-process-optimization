# polyurethane-process-optimization
AI-based analysis for optimizing polyurethane processing conditions

# AI 기반 데이터 분석을 활용한 폴리우레탄 최적 가공조건 탐색

## 📌 프로젝트 개요
폴리우레탄 가공 데이터를 분석하고 AI 기반 모델링을 통해
제품 특성에 영향을 미치는 주요 요인을 파악하여
최적의 가공조건을 탐색하는 프로젝트입니다.

## 🎯 프로젝트 목표
- 폴리우레탄 가공 데이터 분석
- 데이터 전처리 및 EDA
- 주요 가공조건과 물성 간 관계 분석
- 머신러닝을 활용한 물성 예측
- 최적 가공조건 탐색

## 🔄 프로젝트 진행 과정
데이터 이해 → 데이터 전처리 → EDA → 모델링 → 성능 평가 → 최적 조건 탐색

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
